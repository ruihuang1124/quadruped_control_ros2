# Description

1. hardware_* are packages of ros2-control hardware interfaces for different robots.
2. mujoco_simulator describes how to start simulation for different robots.
3. *_controller are different ros2-control controller for different robots.
4. robot_description includes all robot model used in this repo.
5. other functions are developed by creating new ros2 packages as a sub-folder, such as piper_moveit, keyboard_input.
